# Unbound plugin install URLs

34 plugins are available below.

## Install on your iPhone

1. Press and hold a plugin’s **Install URL** link below, then choose **Copy Link**.
2. Open **Unbound → Plugins → +**.
3. Paste the copied URL and tap **Install**.
4. Enable the plugin after installation.

Each URL installs one plugin. If that plugin is already installed, use its existing card in Unbound.
